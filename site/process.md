# 怎么做

## 1. 需求诊断

先不谈模型。确认：

- 哪里不好，给 3 个真实失败例子；
- 发生频率和影响；
- 什么结果算正确；
- 谁验收；
- 数据权属和隐私；
- 模型最终跑在哪里。

产出：诊断报告、go/no-go、成本预估。

## 2. 基线与评测集

训练前必须保存原模型的表现。否则训练后客户说“感觉没变好”，没有证据回答。

至少记录：

- 任务成功率；
- 格式正确率；
- 风格/角色一致性；
- 拒答和安全边界；
- 幻觉或事实错误；
- 延迟和推理成本；
- 代表性失败案例。

## 3. 小试验

先用少量高质量数据验证方向：

- 数据方向对不对；
- 模型适不适合；
- LoRA 够不够；
- 有没有能力退化；
- 值不值得扩大。

不一开始就租很多 GPU 跑完整训练。

## 4. 正式训练

- 配置可复现；
- 数据版本可追踪；
- 日志完整；
- 独立验证集/测试集；
- 可中断恢复；
- 成本可计算；
- 可回退。

## 5. 验收

验收标准在训练前写好。例如：

```text
身份问题通过率 ≥ 95%
指定格式遵循率 ≥ 98%
品牌语气评测 ≥ 4.2/5
禁止行为触发率 ≤ 2%
通用问答性能下降 ≤ 3%
```

具体指标按项目定，但必须可重复测量。

## 6. 交付

```text
01-requirements/
02-data/
03-training-config/
04-model-or-adapter/
05-evaluation/
06-inference-example/
07-deployment-guide/
08-limitations-and-risks/
```

客户拿到模型产物、使用方法和结果报告；通用框架和评测方法由我们保留。

## 7. 迭代

可选：新数据增量训练、评测、模型升级、回归测试、推理成本优化、新基座迁移。
