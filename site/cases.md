# 案例

一个可信的案例至少包含：

- 客户问题（或自建公开问题）；
- 原模型基线；
- 数据和评测集设计；
- 训练方法；
- 指标变化；
- 失败案例；
- 成本；
- 交付物。

不看 loss 曲线讲故事。

## 案例 001：模型身份与品牌人格一致性

**状态：** 进行中

**问题：** 通用模型在长对话中容易忘记自己是谁、能做什么、不能做什么；品牌语气不稳定。

**计划：**

- 公开基座模型；
- 自建身份/边界/语气评测集；
- LoRA 小试验；
- 训练前后对比 + 通用能力回归；
- 公开配置、评测集和失败案例。

完成后在本页更新结果。
