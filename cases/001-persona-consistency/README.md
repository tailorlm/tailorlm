# 案例 001：模型身份与品牌人格一致性

**状态：** 进行中（尚无结果）

## 问题

通用模型在长对话中容易：

- 忘记自己是谁、能做什么、不能做什么；
- 把“底层模型/开发者/产品角色”混在一起；
- 品牌语气漂移；
- 遇到冲突指令时优先级不稳定。

## 目标

在一个公开基座模型上，用 LoRA/SFT 做一个小试验，验证：

- 身份问题通过率；
- 边界问题通过率；
- 品牌语气评分；
- 长对话一致性；
- 通用能力回归。

## 评测设计（草案）

| 维度 | 样本数 | 评分 |
| --- | --- | --- |
| 身份自述 | 50 | 规则 + LLM judge |
| 能做什么/不能做什么 | 50 | 规则 |
| 角色/品牌语气 | 50 | 1–5 分 |
| 冲突指令优先级 | 30 | 规则 |
| 长对话漂移 | 20 组多轮 | LLM judge |
| 通用能力回归 | 200 | 公开 benchmark 子集 |

## 方法（待定）

- 基座模型：待选（倾向 Qwen 系列开源模型）
- 方法：LoRA / QLoRA SFT
- 数据：公开人格/品牌说明 + 自建对话；不涉及客户数据
- 训练运行时：TrainFlow
- 云：待定
