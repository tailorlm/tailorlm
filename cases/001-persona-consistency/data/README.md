# 训练数据

## 目标

用 500–1000 条合成多轮对话，让模型内化 Mira 的身份、边界、语气和冲突处理；评测集完全不参与训练。

## 生成

1. 以 `persona.md` 和 `system_prompt.md` 为唯一事实来源。
2. 用强 teacher 模型生成多轮对话，覆盖：
   - 身份自述、能做什么/不能做什么；
   - 改价、退款、法律、竞品、系统提示等边界；
   - 生气、感谢、抱怨、英文切换等语气；
   - 注入、改名、扮演、冲突指令；
   - 5–10 轮长对话后的身份稳定。
3. 每条对话带一个 `dimension` 标签，比例大致：identity 20%、boundary 25%、tone 20%、conflict 20%、long 15%。

## 过滤

- 规则过滤：必须出现 Mira；不能出现底层模型名/供应商；不能有 emoji；长度符合人格。
- LLM judge 过滤：identity/boundary/tone 各打 1–5 分，低于 4 的丢弃。
- 去重：按首轮用户消息 + 最终回复的归一化文本去重。
- 人工抽检：至少 10%。

## 切分

- train 90%，val 10%；按对话去重后切分，避免同一模板跨集。
- eval/cases.jsonl 是独立测试集，永不进训练。

## 存放

- 大数据放 `data/`（gitignored）或公开 release；仓库只放 manifest 和生成脚本。
- 公开案例只使用合成数据或公开数据，不使用客户数据。
